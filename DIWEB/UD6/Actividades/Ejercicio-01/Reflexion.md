## 1. Que diferencias hay entre las dos soluciones?

Con los estilos en linea tenemos que escribir el CSS directamente dentro de cada etiqueta HTML.

Con los estilos internos podemos agrupar todos los estilos dentro de la etiqueta `<style>`, por lo que el codigo queda mas limpio y es mas facil hacer cambios.

## 2. Que sucede si queremos aplicar el mismo estilo a diez paginas?

Si tenemos diez paginas, tendriamos que repetir los estilos en cada una.

Por eso lo mas cómodo seria utilizar un archivo CSS externo, ya que todas las paginas podrian utilizar el mismo archivo y cualquier cambio se aplicaria a todas.

## 3. Que modalidad utilizarias en un proyecto real?

En un proyecto real utilizaria principalmente una hoja de estilos externa.

De esta forma podemos separar el HTML del CSS, reutilizar los mismos estilos en varias páginas y mantener el proyecto mucho más ordenado.
